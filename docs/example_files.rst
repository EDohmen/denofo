Usage Notes
-----------

- **DNGF files**: These are study annotation files in the De Novo Gene annotation Format, standardized for use with the DENOFO toolkit.
- **Similarities files**: Output from the DENOFO comparator showing methodological similarities between studies.
- **Differences files**: Output from the DENOFO comparator showing methodological differences between studies.
- **FASTA file**: Contains annotated sequences from the corresponding study.

For more information about these files and their usage, please refer to the :doc:`case_studies`, :doc:`comparator`, and :doc:`technical_documentation` sections.
